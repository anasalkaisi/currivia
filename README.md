# Currivia – Studienverlaufsplaner

Currivia ist ein lokaler, quellenbasierter Studienverlaufsplaner. Der aktuelle
Stand ist ein nicht öffentlich freigegebener Entwicklungs-Slice für die
Pilotkonfiguration Medieninformatik an der HdM.

## Lokale Entwicklung

```sh
pnpm install
pnpm dev
```

Der aktuelle S2-Umfang und seine Grenzen stehen in
[`docs/slices/s2-study-history.de.md`](docs/slices/s2-study-history.de.md). S2
baut auf dem quellenbelegten S1-Walking-Skeleton auf.
